# Tasks and Projects

**Last verified:** 2026-05-11 9:00am

WebNesting Tasks helps you and your team organize work, track progress, and stay on top of deadlines -- all from within your workspace. Create projects, break work into tasks, assign team members, and see everything come together across multiple views.

---

## What Are Tasks and Projects?

Tasks is a workspace product that adds project management tools to your workspace. Once enabled, you can create projects to organize related work, add tasks within those projects, assign them to team members, and track progress from start to finish.

You do not need a project for every task. Tasks can also stand on their own as personal items -- quick to-dos or one-off items that do not belong to a larger effort.

> **Tip:** Tasks is a workspace product, which means it is available across your entire workspace and all team members with the right permissions can use it. See [Workspace Products](workspace-products.md) for how to enable it.

---

## Creating a Project

Projects group related tasks together. For example, you might create a project for a website redesign, a marketing campaign, or a product launch.

To create a new project:

1. Go to the **Tasks** section in your workspace sidebar.
2. Click **New Project**.
3. Give your project a name and optionally add a description.
4. Choose a color and icon to make the project easy to identify at a glance.
5. Set a start date and target date if you want to define the project's timeline.
6. Click **Create**.

Your new project appears in the sidebar, and you can start adding tasks right away.

### Project Statuses

Every project has one of three statuses:

- **Active** -- The project is currently being worked on. This is the default status for new projects.
- **Completed** -- The project is finished. You can mark a project as completed when all work is done.
- **Archived** -- The project is no longer active but you want to keep it for reference. Archived projects are hidden from your main project list but can be viewed when you need them.

## Adding Tasks

Tasks are the individual items of work within a project. Each task represents something that needs to get done.

To add a task:

1. Open the project you want to add the task to.
2. Click **Add Task** (or use the quick-add area at the top of your task list).
3. Enter a title for the task.
4. Optionally set additional details like priority, assignee, due date, and description.
5. The task is created and appears in your project.

### Personal Tasks

Not every task belongs to a project. You can also create tasks without assigning them to any project. These personal tasks appear in your **My Work** view and are useful for quick to-dos or items you want to track independently.

## Task Views

One of the most powerful features of Tasks is the ability to see your work in different ways. Each project offers four views, and you can switch between them at any time.

### Board View

The Board view shows your tasks as cards arranged in columns by status -- similar to a Kanban board. Each column represents a status (like To Do, In Progress, or Done), and you drag tasks from one column to the next as work progresses.

This view is great for:

- Seeing the overall flow of work at a glance
- Quickly moving tasks between statuses with drag and drop
- Identifying bottlenecks when one column has too many cards

### List View

The List view shows your tasks in a table format with rows and columns. Each row is a task, and the columns show details like status, priority, assignee, and due date.

This view is great for:

- Scanning through a large number of tasks quickly
- Sorting and filtering tasks by different fields
- Getting a detailed overview of all task information in one place

### Timeline View

The Timeline view shows your tasks on a horizontal timeline, similar to a Gantt chart. Tasks appear as bars spanning from their start date to their due date.

This view is great for:

- Understanding how tasks overlap and relate to each other in time
- Planning schedules and spotting conflicts
- Seeing the overall project timeline from start to finish

### Calendar View

The Calendar view shows your tasks on a monthly or weekly calendar based on their due dates. Tasks appear on the date they are due, giving you a clear picture of upcoming deadlines.

This view is great for:

- Seeing what is due each day or week
- Planning your workload around deadlines
- Making sure nothing falls through the cracks

> **Tip:** Try all four views to find the one that works best for how you think about your work. Many people use the Board view for day-to-day work and switch to the Timeline view for planning.

## My Work

My Work is your personal task hub. It shows all the tasks assigned to you across every project in your workspace, collected in one convenient place.

When you open My Work, you will see:

- **All your assigned tasks** -- Every task where you are the assignee, regardless of which project it belongs to
- **Recently completed tasks** -- Tasks you have finished recently, so you can see your progress

My Work is the best place to start your day. Open it to see everything on your plate, then dive into individual projects as needed.

> **Tip:** My Work pulls tasks from all projects, so you never have to jump between projects to figure out what you should be working on next.

## Managing Tasks

Every task has several properties you can set to keep your work organized.

### Status

Each task has a status that shows where it is in your workflow. Statuses fall into three categories:

- **To Do** -- The task has not been started yet
- **In Progress** -- Someone is actively working on the task
- **Done** -- The task is finished

You can customize the specific statuses available in each project. For example, you might add statuses like "In Review" or "Waiting for Feedback" under the In Progress category.

To change a task's status, click the status badge on the task and select a new status. You can also drag the task to a different column in the Board view.

### Priority

Priority tells your team how urgent a task is. There are four levels:

- **Urgent** -- Needs immediate attention
- **High** -- Important and should be done soon
- **Normal** -- Standard priority (the default)
- **Low** -- Can wait, no rush

### Assigning Tasks

You can assign a task to any team member in your workspace. The assignee is the person responsible for completing the task. Assigned tasks appear in that person's My Work view.

To assign a task, open it and select a team member from the assignee field. You can change the assignee at any time.

### Dates

Tasks support two types of dates:

- **Due date** -- When the task needs to be finished
- **Start date** -- When work on the task should begin

Both dates are optional. Tasks with due dates appear on the Calendar view and show on the Timeline view. Setting both a start date and due date lets the Timeline view display the task as a bar spanning the full duration of work.

### Estimated Hours

You can set an estimated number of hours for a task to help with planning. This gives your team a sense of how much work is involved before they begin.

### Completing and Reopening Tasks

When a task is finished, change its status to a Done status to mark it as complete. If you need to revisit a completed task, you can reopen it by changing its status back to a To Do or In Progress status.

## Subtasks and Checklists

For tasks that involve multiple steps, you have two ways to break them down.

### Subtasks

Subtasks are full tasks nested under a parent task. Each subtask has its own status, priority, assignee, and all the other properties of a regular task. Use subtasks when the individual steps are substantial enough to track independently.

To add a subtask, open a task and look for the subtask section. Click **Add Subtask** and fill in the details just like you would for any other task.

### Checklists

Checklists are simpler -- they are a list of items within a task that you check off as you complete them. Each checklist item can have an assignee, but they do not have their own status, priority, or other task properties.

Use checklists for quick, lightweight steps that do not need individual tracking. For example, a task called "Prepare launch materials" might have a checklist with items like "Write announcement email," "Update website banner," and "Post on social media."

> **Tip:** Use subtasks for steps that are complex enough to need their own assignee, status, and due date. Use checklists for simpler items you just need to check off.

## Dependencies

Sometimes one task cannot start until another task is finished. Dependencies let you define these relationships so your team knows the order of work.

When you set a dependency, you are saying that one task **blocks** another. The blocked task cannot move forward until the blocking task is complete.

To add a dependency:

1. Open the task that is waiting on another task.
2. Look for the **Dependencies** section.
3. Add the task that needs to be completed first.

Dependencies are especially useful in the Timeline view, where you can see how tasks connect and how delays in one task might affect others downstream.

> **Important:** Dependencies help your team understand the order of work, but they do not prevent someone from working on a blocked task. They serve as a visual guide and planning tool.

## Milestones

Milestones are key deadlines or checkpoints within a project. They mark important moments -- like the end of a phase, a client review, or a launch date.

Unlike tasks, milestones do not represent work to be done. They represent a point in time that your project is working toward.

To add a milestone:

1. Open your project.
2. Look for the **Milestones** section.
3. Click **Add Milestone** and set a name and date.

Milestones appear on the Timeline view as markers, making it easy to see how your tasks relate to upcoming deadlines.

> **Tip:** Use milestones to break a long project into phases. They give your team clear targets to work toward and make progress easier to measure.

## Time Tracking

Time tracking lets your team log the hours they spend on tasks. This is useful for understanding how long work actually takes, billing clients for hours worked, or improving future estimates.

### Logging Time

To log time on a task:

1. Open the task you worked on.
2. Look for the **Time Tracking** section.
3. Click **Log Time**.
4. Enter the number of hours spent.
5. Optionally add a description of what you worked on.
6. Mark the time as **billable** if it should be billed to a client.
7. Save your time entry.

You can log multiple time entries on the same task -- one for each work session.

### Time Reports

Time reports give you a summary of time logged across your workspace. You can filter time reports by:

- **Team member** -- See how much time each person has logged
- **Project** -- See how much time has been spent on a specific project
- **Date range** -- Focus on a specific time period

Time reports help you understand where your team's effort is going and whether projects are staying on track.

## Tags

Tags let you organize and categorize tasks across projects. You might use tags like "Design," "Bug Fix," "Client Request," or "Quick Win" to group related tasks together regardless of which project they belong to.

To add a tag to a task, open the task and look for the **Tags** field. You can add existing tags or create new ones. A task can have multiple tags.

Tags are shared across your workspace, so the same tag can be used in different projects. This makes it easy to find all tasks related to a specific topic, no matter where they live.

> **Tip:** Keep your tags consistent. Agree with your team on a set of standard tags so everyone uses the same ones. This makes filtering and searching much more effective.

## Comments and Activity

Every task has a comment section where you and your team can discuss the work, share updates, ask questions, or leave notes.

### Comments

To add a comment, open a task and scroll to the comments section. Type your message and click **Post**. Comments appear in chronological order so everyone can follow the conversation.

### Activity Log

Each task also has an activity log that automatically records every change made to the task -- who changed the status, when the priority was updated, when a subtask was added, and so on. The activity log gives you a complete history of the task without anyone needing to write it down.

> **Tip:** Use comments for discussion and questions. The activity log handles the record-keeping automatically, so you do not need to manually document every status change.

## Cloning a Project

If you have a project structure you want to reuse -- for example, a recurring client onboarding process or a monthly reporting workflow -- you can clone an existing project.

When you clone a project, a new project is created with the same structure. You can choose to include milestones in the clone. Task assignees, dates, and statuses start fresh in the new project so you can set them up for the new round of work.

To clone a project:

1. Open the project you want to duplicate.
2. Look for the **Clone** option in the project settings or menu.
3. Choose whether to include milestones.
4. Give the new project a name.
5. Click **Clone**.

## Tips

- **Start with one project.** If you are new to task management, create a single project and get comfortable before adding more. You can always expand later.
- **Use the Board view for daily work.** The drag-and-drop Kanban board is the fastest way to move tasks through your workflow during the day.
- **Check My Work every morning.** It takes just a few seconds to see everything on your plate across all projects.
- **Keep task titles clear and actionable.** Instead of "Website," try "Update homepage hero section." Specific titles make it easier for everyone to understand what needs to be done.
- **Set due dates on important tasks.** Tasks without due dates are easy to forget. Even a rough deadline helps keep things moving.
- **Use subtasks to break down big tasks.** If a task feels too large, split it into smaller subtasks. Smaller steps are easier to start and more satisfying to complete.
- **Log time as you go.** It is easier and more accurate to log time right after you finish working on something than to try to remember at the end of the week.
- **Review your projects regularly.** Set aside time each week to review project progress, update statuses, and adjust priorities as needed.

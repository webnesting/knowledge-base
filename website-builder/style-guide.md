# Your Style Guide Page

**Last verified:** 2026-10-24 1:35pm

## What it is

Every WebNesting site has a **Style Guide** page. It shows every block you can add in the builder, in your site's own theme, on one page. Use it to see how your colors, fonts and buttons look on each kind of block, and to copy a ready-made block onto another page.

The page lives at `/style-guide` on your site (for example, `yoursite.com/style-guide`). It is not in your menus or your sitemap, so visitors only find it if they have the address. To open it in the builder, click the **Pages** icon in the column of icons on the right, then click **Style Guide**.

## How it works

The page starts with a short introduction. Then it has one section for each group in the builder's **Add** panel, in the same order: Layout, Text, Media, Interactive, Marketing, Site modules and Sections.

- Each block appears under its name, the way it looks when you first add it to a page.
- Blocks that start out empty, such as a Blank box, Inline Text or an Alert, show a line of sample text, so you can see how they look in your theme.
- The **Text** section starts with samples of headings, paragraphs, a quote, lists, a picture and a divider line.
- Blocks that only some sites can use (for example, blocks for a module you have not turned on) appear only on the sites that can use them.

Some blocks need something from you before they show on your live site:

| Block | What it needs |
|-------|---------------|
| Image, Image comparison, Slideshow, Logo strip | Pictures from your Media Library |
| Video, Video background, Animation (Lottie), Audio, File download | A file, or for a video a link |
| 3D scene (Spline), Booking form, Social post | A link from that service |
| Podcast episodes | Your podcast's feed address |
| Site menu | Pages added to your site menu |
| Login, Registration, Forgot Password, Reset Password and Account Security forms | Accounts turned on for your site (**Modules**, then **Accounts**) |
| Light / dark switch | The setting that lets visitors switch between light and dark |
| Menu button | A narrow screen, such as a phone. It opens the site menu there |

On the live Style Guide page, each of these blocks shows a short grey line under its name that says what it needs. In the builder, each one also shows a box that says what it needs.

When you open the page in the builder, you see this note above the page:

> This page is an example page of all builder components and can not be edited

On this page the **Add**, **Settings** and **Styles** panels are hidden, the **Publish** button is turned off, and you cannot type into text, drag blocks, or delete, cut or paste them. You can still click any block to select it, look through the **Layers** panel, and copy a block. The page's title and search engine (SEO) settings are still yours to change, the same as on any page.

To use a block from the Style Guide on another page:

1. Open the Style Guide page in the builder.
2. Click the block you want, so it is selected.
3. Click the **Copy** button on the small toolbar above the block. You can also right-click the block and choose **Copy**, or press **Ctrl + C** (**Cmd + C** on a Mac).
4. Open the **Pages** panel and click the page where you want the block.
5. Click the block that should come just before the new one.
6. Press **Ctrl + V** (**Cmd + V** on a Mac), or right-click and choose **Paste**.

The block is pasted right after the one you selected. It is now an ordinary block on that page, so you can edit, style and move it like any other.

> **Tip:** To see how all of your blocks look in a different theme, change your site's theme and then open the Style Guide page again.

## Why it works this way

WebNesting rebuilds the Style Guide page by itself. When WebNesting adds a new block or improves one, your Style Guide page changes with it, so it always shows every block as it is today. Any change you made to the page would be lost at the next rebuild, which is why the page cannot be edited.
